# Проверки CDDA FPV 0.4

## Выполнено

- Изменённые `handle_action.cpp`, `cata_tiles.cpp`, `sdltiles.cpp` скомпилированы настоящим Windows x64 MinGW-w64 GCC 15.2.1 с SDL-заголовками. Это не только поиск текста и не сборка веб-макета.
- Самостоятельный тест камеры/CPU-рендерера: 19236 успешных проверок. **19200 из них — попиксельные проверки отсутствия NaN**, а не отдельные игровые сценарии.
- В тесте проверяются направления камеры, свободная/связанная мышь, восстановление контекста ввода, альфа-композиция, перекрытия, прозрачные пиксели спрайтов, пол/потолок, отверстие между уровнями, туман неизвестных клеток, отсечение ближней плоскостью.
- Добавлены проверки прозрачного стекла перед объектом, перекрытия стекла непрозрачной стеной, сохранения непрозрачного depth buffer, выбора объекта по пикселю, границ viewport и недопустимых индексов цели.
- Тот же тест собран в Windows `.exe` и запущен под Wine 9.0 x64: 19236 проверок пройдены.
- Чтение SDL-атласа: 11 проверок цвета и восстановления состояния SDL-рендерера пройдены повторно.
- В точной функции HUD из исходника, но с тестовой реализацией шрифта/renderer: по 325 проверок границ и непересечения кнопок для окон шириной 960 и 390 пикселей. Все 11 кнопок действий доступны в обоих размерах.
- Тестовые изображения панели просмотрены визуально. Это изображения отдельного стенда, **не скриншоты запущенной игры**.
- Патч проверен `patch --dry-run -p1` на чистых исходных файлах тега `0.I-1`.

## Полная сборка и игровые проверки

- Полностью собран и слинкован настоящий `cataclysm-tiles.exe`: Windows PE32+ x86-64. После исправлений HUD выполнена успешная повторная компиляция и линковка.
- EXE запущен под Wine 9.0 x64 с SDL software renderer: `--help` завершился с кодом 0, главное меню загрузилось.
- Созданы новый мир и персонаж; загружено тестовое сохранение. Переключение F6 и поворот на 45° через h работают.
- В реальном игровом мире открыта встроенная панель, выбран предмет, выполнен Put на пол: штатный журнал подтвердил сброс и время изменилось на 1 секунду. Затем выполнен Take: журнал подтвердил подбор, предмет вернулся в инвентарь.
- Клик по отрисованному NPC выбрал его клетку; кнопка Interact открыла штатное меню действий именно с этим NPC.
- В окончательном EXE проверена панель с настоящими именами вещей: служебные цветовые теги больше не отображаются, фиктивная строка «none» отсутствует.
- Проверены включение/выключение захвата мыши F7/Esc и изменение ракурса мышью без хода игрового времени.
- Правый штатный sidebar остаётся видимым на игровых скриншотах.
- Это smoke-test под Wine, а не подтверждение совместимости со всеми версиями Windows и видеодрайверами. Полный игровой прогон стекла, лестниц и боевых сценариев не выполнен.

## Пределы этих проверок

Unit-тест рендерера и сборка не доказывают отсутствие игровых ошибок.
Не выполнен полный игровой регрессионный прогон всех предметов, NPC, транспорта, лестниц и тайлсетов.
Нет проверки на реальной Windows, пользовательском GPU/драйвере и пользовательском сохранении.
Прозрачность не заменяет физику игры. Лестничная геометрия процедурная, ориентирована приближённо.
Штатные сложные меню остаются. Встроенный правый список не раскрывает транспортное хранилище
и вложенные контейнеры на земле.

## Воспроизведение unit-теста

Компилятор C++17:

```sh
g++ -std=c++17 -O1 -Wall -Wextra -Werror test_renderer.cpp -o test_renderer
./test_renderer
```

Для теста SDL нужны SDL2 и SDL2_image. Файлы `renderer-test.log`, `sdl-test.log`,
`wine-renderer-test.log` и `windows-changed-files.log` содержат результаты соответствующих проверок.
