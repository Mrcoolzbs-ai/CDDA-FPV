# Проверки CDDA-FPV 0.4.1 RU

## Русификация: выполнено

- Включена сборка с LOCALIZE=1. Используется официальный lang/po/ru.po из CDDA 0.I-1, дополненный переводами новых строк FPV.
- MO-каталог успешно собран обычной командой проекта msgfmt -f. Проверено чтение русского каталога через Python gettext и переводы подписей панели.
- Строгая проверка msgfmt --check сообщает о существующих форматных ошибках официального русского перевода. Диагностика побайтно сопоставлена с неизменённым ru.po тега 0.I-1: совпадает. Новых ошибок этой проверки изменения FPV не добавляют; весь upstream-каталог не исправлялся.
- Тест извлекает настоящую draw_first_person_hud из src/sdltiles.cpp и использует UTF-8-совместимые тестовые реализации шрифта и renderer: 3222 проверки границ, непересечения и наличия кнопок в 18 раскладках (ширина 390/600/960, ширина символа 8/12/16, HUD/инвентарь).
- После увеличения шрифта обнаружено исчезновение последней кнопки; исправлено динамическим резервированием числа строк действий по фактической ширине русского текста. Все 11 действий и закрытие доступны во всех 18 тестовых раскладках.
- Этот тест раскладки не проверяет настоящие глифы шрифта и не заменяет запуск полной игры.
- Повторно пройден самостоятельный тест камеры/рендерера: 19236 проверок, из них 19200 — попиксельные проверки NaN, не отдельные игровые сценарии.

## Полная сборка 0.4.1 RU и запуск игры: выполнено

- Полная компиляция и линковка ru-cataclysm-tiles.exe завершились успешно. Это Windows x64 PE32+, не HTML-демонстрация. Сборка с LOCALIZE=1, TILES=1, SOUND=1.
- EXE --help завершился с кодом 0 под Wine 9.0 x64; затем запущена полная игра с SDL software renderer.
- С минимальным config/options.json (только USE_LANG=ru) главное меню отображается по-русски без ручного переключения языка.
- Загружено тестовое сохранение: русский стандартный sidebar, сообщения, названия предметов и клеток; несколько непереведённых названий официального каталога остаются английскими.
- Проверены F6, русские HUD и встроенный инвентарь: кириллица читается, все кнопки присутствуют, правая панель сохраняется.
- В русской панели мышью выбрана вещь, выполнено «Положить», затем «Взять» из правой колонки. Оба действия подтверждены русским игровым журналом и изменением игрового времени.
- Скриншоты настоящей игры, а не тестового стенда: fpv/screenshots/. Старые английские записи журнала на них относятся к тестовому сохранению до переключения языка.

## Ограничения проверки

Нет проверки на настоящей Windows, пользовательском GPU/драйвере или пользовательском сохранении.
Полный регрессионный прогон всех существ, предметов, боевых действий, видов стекла, лестниц и тайлсетов не выполнен.
Лестничная геометрия приближённая. Транспортное хранилище и вложенные контейнеры на земле не раскрываются во встроенной правой колонке.
Штатные сложные меню сохранены. Оригинальный перевод CDDA может содержать английские строки.

## Воспроизведение из корня репозитория

```sh
c++ -std=c++17 -O1 fpv/tests/test_renderer.cpp -o /tmp/cdda-fpv-renderer-test
/tmp/cdda-fpv-renderer-test
python3 fpv/tests/test_hud_layout.py
```

Для теста HUD нужны Python 3, msgfmt и компилятор C++17. Это тест размеров/управления, не реалистичный графический стенд.
