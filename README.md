# CDDA-FPV 0.4.1 — экспериментальный вид от первого лица

Основа: исходники CleverRaven/Cataclysm-DDA, точный тег `0.I-1`.
Это отдельная модифицированная сборка игры, а не JSON-мод: движок и рендер изменены на C++.

## Запуск

1. Полностью распакуйте архив в отдельную папку. Не запускайте EXE из ZIP.
2. Запустите `START-CDDA-FPV.bat` или `cataclysm-tiles.exe` из этой папки.
3. Создайте новый тестовый мир и персонажа. Не переносите единственную копию сохранений.
4. В игре нажмите **F6**, чтобы включить вид от первого лица. F6 возвращает штатный вид сверху.

В русской сборке включена штатная локализация CDDA (`LOCALIZE=1`), переведены HUD, панель вещей и настройки FPV. В комплекте базовый набор звуков,
без сторонних звуковых пакетов. Установленная оригинальная игра не требуется.
Не удаляйте DLL, `data`, `gfx` и `lang` рядом с EXE. Сборка не подписана цифровым сертификатом.

## Управление

- **F6** — переключение вида сверху / первого лица (пешком).
- **F7** — свободный обзор мышью; **Esc** освобождает мышь.
- **h / l** — поворот на 45° влево/вправо, **k / j** — вперёд/назад при заводских vi-назначениях CDDA.
- Клавиши обычного движения: вперёд/назад относительно направления движения, влево/вправо — поворот на 45°;
  диагональные направления сохраняются. Обзор мышью по умолчанию не меняет направление движения.
- В настройках графики: `FPV_LINK_SPRITE` связывает мышиный поворот с направлением движения и
  доступным в CDDA разворотом спрайта влево/вправо (не добавляет восьмиракурсные спрайты).
- **i** / кнопка **Инвентарь** — встроенный инвентарь.
- Клик по объекту сцены — выбрать клетку/существо и открыть панель.
  При захваченной мыши клик выбирает объект под центральным прицелом.
- **e** / **Осмотреть**, **g** / **Взять** — открыть панель объекта под прицелом.
- **Esc** / **Закрыть** — закрыть встроенную панель. Движение также закрывает её.
- Стандартные назначения клавиш CDDA можно менять; здесь указаны заводские назначения.

## Встроенная панель

Слева — вещи персонажа, включая содержимое контейнеров, справа — видимые предметы выбранной клетки.
Кликните строку предмета, затем действие:

- **Взять** — забрать выбранную вещь из клетки штатной деятельностью подбора.
- **Положить** — положить выбранную вещь персонажа на выбранную клетку штатной деятельностью сброса.
- **В руки / Надеть / Применить** — взять в руки / надеть / использовать выбранную вещь.
- **< / >** — страницы каждого списка отдельно.
- **Действие** — штатное взаимодействие с выбранной клеткой или существом:
  например, меню NPC, взаимодействие с питомцем, исследование мебели.
- **Атаковать** — обычная атака движением по соседнему существу; сохраняются safe mode и штатные подтверждения.
  Издалека кнопка не атакует и не перемещает персонажа к цели.
- **Открыть / Закрыть** — открыть / закрыть на выбранной соседней клетке.
- **Вверх / Вниз** — обычный переход вверх/вниз **на клетке, где стоит персонаж**, не телепортация к выбранной лестнице.

Действия проверяют текущую достижимость; подбирать через стены, с другого этажа или из закрытой
непрозрачной/запечатанной мебели панель не позволяет. Дальняя видимая клетка доступна только для просмотра.
Количество, вес, объём, время и деятельность обрабатывает сама игра.
Сложные действия и диалоги по-прежнему могут открывать штатные окна CDDA.
Грузовые отсеки транспорта и содержимое контейнеров на земле отдельно в правом списке пока не раскрываются.

## Рендер

- Стекло рисуется в фиксированной плоскости стены с рамой и отдельным проходом прозрачности,
  а не поворачивающимся к камере спрайтом. Битые/открытые окна не получают целую стеклянную панель.
- Закрытые непрозрачные окна остаются непрозрачными. Сами правила света, видимости и проходимости не меняются.
- Для лестниц рисуются ступени между уровнями; для распознанных по ID лестниц-стремянок — перекладины.
  Это процедурная приближённая геометрия: ориентация/соединение всех специальных лестниц ещё не воспроизводятся точно.
- Этажи учитывают видимость CDDA; невидимые клетки не показывают настоящие объекты.
- Предметы на распознанных поверхностях размещаются выше пола. Существа — билборды из игрового тайлсета.
- Штатная правая панель с состоянием персонажа и картой сохранена.

## Важно

Это экспериментальный прототип, не готовая замена всех интерфейсов и геометрии CDDA.
Автомобили, сложная мебель, уникальные сооружения и все варианты тайлсетов пока не моделируются точно.
CPU-рендерер может работать медленно. Попробуйте уменьшить `FPV_RENDER_WIDTH`, `FPV_RANGE`, `FPV_Z_RADIUS`.
Для проверки лестниц нескольких уровней рекомендуется включённая в исходной игре 3D-видимость.
Параметры `FPV_*` находятся в настройках графики.

Точный перечень выполненных проверок — в `TEST_REPORT.md`. Отдельный запуск под Wine не равен проверке
на настоящей Windows и на вашем видеодрайвере.

При проблеме полезны: текст ошибки, скриншот, `config/debug.log`, название тайлсета,
действие непосредственно перед сбоем и минимальное тестовое сохранение (без личных данных).

## Русский язык

В готовом Windows-архиве русский включён файлом `config/options.json`.
Если используете свои настройки, выберите русский язык в **Settings → Options → Interface → Language**, сохраните и перезапустите игру.
Используется официальный русский каталог именно из `0.I-1`; непереведённые строки оригинала могут оставаться английскими.
Для самостоятельной сборки: `make -C lang LANGUAGES=ru`. Каталог `lang/mo/ru/LC_MESSAGES/cataclysm-dda.mo` должен лежать рядом с игрой по этому относительному пути.
Настройки и сохранения тестового персонажа в репозиторий и дистрибутив не включены.
